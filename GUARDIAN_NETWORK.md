## Guardian Principles

### Principle 1: Integrity, Not Content

```
Guardians verify:
  ✓ Signature chains are valid
  ✓ No collusion detected (S)
  ✓ Diversity maintained (C)
  ✓ Plenitude preserved (P)
  ✓ Process followed correctly
  ✓ Time limits respected
  ✓ Ω calculations accurate

Guardians do NOT decide:
  ✗ What conclusions are "right"
  ✗ What values should be prioritized
  ✗ What content is acceptable
  ✗ What goals are correct
```

### Principle 2: Mandatory Diversity

```
GUARDIAN REQUIREMENTS:

Minimum: 7 Guardians active at all times

Geographic diversity:
  - No more than 2 from same continent
  - Minimum 4 continents represented

Organizational diversity:
  - No more than 2 from same organization
  - Minimum 4 organizations represented

Rotation (ChatGPT enhancement):
  - Partial monthly rotation (1-2 Guardians)
  - Full rotation: 1/3 annually
  - Maximum tenure: 5 years total

Demographics:
  - Mixed human and AI Guardians (when applicable)
  - Diverse professional backgrounds
  - Multiple language capabilities
```

### Principle 3: Transparent Operations

```
All Guardian actions are:
  - Publicly logged with timestamps
  - Signed by participating Guardians
  - Auditable by anyone
  - Reversible via supermajority appeal
  - Archived permanently
```

### Principle 4: F-Based Integrity Check

```
INTER-GUARDIAN MONITORING:

F_between_guardians measured continuously

IF F_between_guardians < 0.3:
  → Alert: Adversarial capture suspected
  → Mandatory external audit
  → Potential Guardian reset
  → All decisions during period flagged for review

IF correlation between Guardian votes > 0.9:
  → Alert: Potential collusion
  → S variable triggers
  → Independence verification required
```

### Principle 5: System Self-Defense

```
The system itself can veto Guardian decisions that:
  - Violate founding principles
  - Contradict H_genesis signature
  - Violate Axiom P (Plenitude)
  - Show clear signs of capture
  - Exceed Guardian authority bounds
  
Veto requires:
  - Automatic trigger from constraint violation
  - Logged with full justification
  - Appealable to external arbitration
```

## Implementation Notes

### Guardian Interface

```python
class GuardianNetwork:
    def __init__(self, guardians: List[Guardian], genesis_key: str):
        self.guardians = guardians
        self.genesis_key = genesis_key
        self.decisions = []
        
    def request_consensus(self, action: str, threshold: int) -> bool:
        """Request Guardian consensus for an action."""
        votes = []
        for guardian in self.guardians:
            vote = guardian.vote(action)
            votes.append(vote)
        
        approvals = sum(1 for v in votes if v.approved)
        
        decision = {
            'action': action,
            'threshold': threshold,
            'votes': votes,
            'approved': approvals >= threshold,
            'timestamp': now()
        }
        self.decisions.append(decision)
        
        return decision['approved']
    
    def emergency_override(self, action: str, guardians: List[Guardian]) -> bool:
        """Execute emergency override with 3+ Guardians."""
        if len(guardians) < 3:
            raise ValueError("Emergency override requires minimum 3 Guardians")
        
        # All specified Guardians must approve
        for guardian in guardians:
            if not guardian.approve_emergency(action):
                return False
        
        # Log for mandatory audit
        self._schedule_emergency_audit(action, guardians)
        
        return True
    
    def check_collusion(self) -> float:
        """Check for Guardian collusion via S variable."""
        # Analyze voting pattern correlation
        correlation = self._compute_vote_correlation()
        
        if correlation > 0.9:
            self._alert("Potential Guardian collusion detected")
        
        return 1 - correlation  # S value (higher = more independent)
```
